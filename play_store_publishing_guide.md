# Google Play Store Publishing Guide for BhoomiTayi

This guide outlines the step-by-step process for compiling, signing, and publishing the **BhoomiTayi** Android application to the Google Play Store.

---

Every time you change Capacitor settings, update native plugins, or make adjustments to the web config, you must run the Capacitor sync:

```powershell
# Sync configuration and web assets with the native Android project
npx cap sync android
```

## 3. Configuring Android Project settings

All Android native code is stored in the [android](file:///C:/Users/amogh/bhoomitayi/android) directory.

### A. Updating Version Codes (Every Release)
Each update uploaded to the Google Play Console requires a unique and incremented version code.
Open the [android/app/build.gradle](file:///C:/Users/amogh/bhoomitayi/android/app/build.gradle) file and modify these fields:

- `versionCode`: Increment by 1 (e.g., `1`, `2`, `3`...).
- `versionName`: Semantic versioning of your app (e.g., `"1.0.0"`, `"1.0.1"`...).

```groovy
defaultConfig {
    applicationId "com.bhoomitayi.app"
    minSdkVersion rootProject.ext.minSdkVersion
    targetSdkVersion rootProject.ext.targetSdkVersion
    versionCode 2 // Increment this
    versionName "1.0.1" // Update this string
    testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner"
}
```

### B. Checking Android Manifest
Verify [AndroidManifest.xml](file:///C:/Users/amogh/bhoomitayi/android/app/src/main/AndroidManifest.xml) contains the correct permissions, specifically:
- `android.permission.INTERNET` (Required since your app loads resources from Vercel).

## 4. Google Sign-In & Firebase Configuration (Crucial)

Since BhoomiTayi uses `@capacitor-firebase/authentication` for Google Sign-in, you **must** configure SHA fingerprint credentials, otherwise Google Sign-In will fail in production.

### A. Extracting Sign-In Fingerprints
When you publish an app, there are **two sets of SHA keys**:
1. **Upload Key:** The keystore you use to sign the app before uploading it.
2. **App Signing Key:** The final key generated by Google Play Console (if you opt into Google Play App Signing).

#### Step 1: Generate your local Upload Keystore
If you don't have a keystore file yet, generate one:
```powershell
keytool -genkey -v -keystore bhoomitayi-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias bhoomitayi-key-alias
```
*Keep this keystore file and its passwords safe! If lost, you cannot update your app.*

#### Step 2: Get Fingerprints from Keystore
To extract the SHA-1 and SHA-256 fingerprint:
```powershell
keytool -list -v -keystore bhoomitayi-release.jks -alias bhoomitayi-key-alias
```

### B. Configuring Firebase & Google Developer Console
1. Go to your [Firebase Console](https://console.firebase.google.com/) > **Project Settings**.
2. Under **Your Apps > Android App (`com.bhoomitayi.app`)**, click **Add Fingerprint**.
3. Add the **SHA-1** and **SHA-256** fingerprints of your **Upload Key**.
4. Go to **Google Play Console > Setup > App Integrity > App Signing** to get the Google Play App Signing Certificate SHA fingerprints. Add these to Firebase Console as well.
5. Download the updated `google-services.json` and replace it in:
   `android/app/google-services.json`
6. Re-run `npx cap sync android` to apply the updated file.

## 5. Generating the Signed Android App Bundle (AAB)

> [!IMPORTANT]
> Google Play Store requires the **Android App Bundle (.aab)** format for all new app releases, rather than `.apk`.

You can build this via **Android Studio** (Recommended) or the **Gradle CLI**.

### Method A: Build via Android Studio (Visual)
1. Open the [android](file:///C:/Users/amogh/bhoomitayi/android) folder in **Android Studio**.
2. Go to the menu: **Build > Generate Signed Bundle / APK...**
3. Select **Android App Bundle** and click **Next**.
4. Choose your keystore (`bhoomitayi-release.jks`), enter the key alias and password details.
5. Set Build Variant to **release** and signature versions.
6. Click **Create** or **Finish**.
7. Once finished, Android Studio will output the file:
   `android/app/release/app-release.aab`

### Method B: Build via CLI
If you want to configure automated builds, edit [android/app/build.gradle](file:///C:/Users/amogh/bhoomitayi/android/app/build.gradle) to define the signingConfigs, and run:
```powershell
cd android
./gradlew bundleRelease
```

## 6. Uploading to Google Play Console

### Step 1: Create Your App
1. Go to the [Google Play Developer Console](https://play.google.com/console).
2. Click **Create app**.
3. Fill in:
   - **App name:** `BhoomiTayi`
   - **Default language:** English / English (India)
   - **App or Game:** App
   - **Free or Paid:** Free
   - Accept declarations and click **Create app**.

### Step 2: Set Up Your App (Dashboard Tasks)
Complete all initial setup tasks under the **Dashboard** checklist:
- Set Privacy Policy URL.
- Declare ad preferences (Declaration on whether the app contains ads).
- Declare access credentials (if app requires login).
- Complete Content Rating questionnaire.
- Declare Target Audience and Content (e.g. 18+ or general).
- Fill out the News apps and Data Safety forms.

### Step 3: Complete Main Store Listing
Provide app branding assets:
- **Short Description:** Quick summary of your real estate platform.
- **Full Description:** Comprehensive details.
- **App Icon:** 512 x 512 pixels (PNG/JPEG format, max 1MB).
- **Feature Graphic:** 1024 x 500 pixels.
- **Screenshots:** Upload phone and tablet screenshots showcasing major views.

### Step 4: Create a Release & Upload AAB
1. Navigate to **Testing > Internal testing** (recommended for initial testing) or **Production**.
2. Click **Create new release**.
3. Under **App bundles**, upload your `.aab` file (`app-release.aab`).
4. Enter release notes explaining changes.
5. Click **Save** and then **Review release**.
6. When satisfied, click **Start rollout**.
